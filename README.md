# Akash Kumar Reddy Jampana — Portfolio

A professional, minimal portfolio website built with React and Tailwind CSS.

**Live Site:** [https://jampanaakash.github.io/Portfolio](https://jampanaakash.github.io/Portfolio)

## Quick Start

```bash
yarn install
yarn start
```

## Edit Content

All content is in **`src/data/siteConfig.js`** — update your name, bio, skills, experience, projects, and contact info there. No need to touch any other files.

## Deploy

```bash
yarn build
```

Then push the `build/` folder to the `gh-pages` branch.

## Tech Stack

- React 19
- Tailwind CSS
- Lucide Icons
- DM Sans + Inter fonts
